# יאללה ערבית · يلا عربي

משחק דפדפן ללימוד ערבית מדוברת פלסטינית. המשחק הוא קובץ HTML אחד, בלי התקנה ובלי שרת. פותחים את `index.html` בדפדפן ומשחקים.

## מה יש במשחק
- **10 נושאים, 127 מילים וביטויים**: ברכות, מילות יסוד, שאלות, מספרים, משפחה, אוכל, צבעים, בעיר, זמן וביטויים לשיחה. לכל מילה יש כתב ערבי, תעתיק עברי, פירוש והערות (למשל צורת הנקבה).
- **לימוד**: כרטיסיות שאפשר להפוך, עם השמעה.
- **חידון**: מערבית לעברית, מעברית לערבית ושאלות האזנה. יש בונוס על רצף תשובות נכונות, ומילה שטעיתם בה חוזרת בסוף הסבב.
- **זיכרון**: מוצאים זוגות של מילה בערבית ופירושה בעברית.
- **בניית משפטים**: מסדרים מילים למשפט שלם.
- **אתגר 60 שניות**: כמה שיותר תשובות נכונות, עם שמירת שיא.
- **התקדמות**: XP, רמות, יעד יומי ורצף ימים. חזרה מרווחת פשוטה (שיטת לייטנר) גורמת למילים שקשות לכם להופיע יותר.
- ההתקדמות נשמרת בדפדפן (localStorage). יש מצב כהה, תמיכה בטלפון, ושליטה במקלדת (1–4 לבחירת תשובה).

## הערות על הניב
התעתיק מבוסס על ההגייה העירונית (ירושלים, הגליל, שכם): ق נהגית כ-א (قهوة = אַהְוֶה), ث/ذ נהגות ת/ד. מדריך הגייה מלא נמצא בתוך המשחק.
ההשמעה משתמשת בקול הערבי שמותקן בדפדפן. לרוב הוא מבטא בערבית ספרותית, ולכן כשיש הבדל כדאי לסמוך על התעתיק.

## הרצה
```
open index.html        # או: python3 -m http.server ואז http://localhost:8000
```
אפשר גם לפרסם דרך GitHub Pages מהענף הראשי.
