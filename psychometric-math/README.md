# חשבון מהיר לפסיכומטרי

אתר בקובץ HTML אחד לתרגול חשבון בראש לקראת הפרק הכמותי. פותחים את `index.html` בדפדפן, בלי התקנה.

- **חיבור וחיסור**: מספרים דו־ספרתיים, תלת־ספרתיים או מעורב (רוב השאלות כוללות העברה או פריטה)
- **לוח הכפל**: עד 10×10 או עד 12×12, אפשר להוסיף שאלות חילוק
- **ריבועים 11–16**: ריבוע, שורש או מעורב
- **מבחן מעורב**: כל הנושאים יחד
- 10 או 20 שאלות, או ספרינט של 60 שניות
- טיפ לפתרון אחרי כל טעות, סיכום בסוף ותרגול חוזר של הטעויות בלבד
- דפי לימוד: שיטות לחישוב מהיר, לוח כפל אינטראקטיבי, כרטיסיות ריבועים
